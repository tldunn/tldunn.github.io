# tldunn.github.io
Portfolio showcasing various projects for graphics, animation, and rendering

**Bounding Boxes**  
The bounding boxes video showcases building bounding boxes and characters interacting with them. This video specifically shows the case of a character colliding with the bounding box of a car as well as colliding with the bounding box of a building. 

**Character Behavior**  
The character behavior video demonstrates various behaviors that were implemented on NPC characters. Different behaviors implemented were partial body animation (stand and shoot) and full body (running or walking). Additionally, this video shows characters following waypoints.

**Dissolve Shader Cube and Dissolve Shader Model**  
These videos show a TRON-styled dissolve shader material in Unity, on two different objects. In the first video, we have a standard 3D cube object with the dissolve material on it. The second video demonstrates the dissolve shader material on an FBX model. 

**Dissolve Shader**  
This pdf goes into depth about the journey of creating the TRON-styled dissolve shader in Unity. 

**Inverse Kinematics**  
Displays the implementation of forwards and inverse kinematics with skinning to deform a character via joint hierarchy

**Jelly Cube**  
This video depicts a simulation of a jelly cube using physics, specifically a mass spring system.
